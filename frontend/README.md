# HOS Trip Master

Trip route planning and FMCSA Hours of Service (HOS) daily log generator.

## Features
- Route calculation with waypoints and stops
- FMCSA 70h / 8-day compliance tracking
- Automatic 10-hour rest, 30-minute break, and fuel stop scheduling
- Interactive route map with Leaflet
- Driver daily log sheets and print layouts

## Development
- Frontend: `npm run dev`
- Backend: `python manage.py runserver`
